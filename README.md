# MinesweeperGame
A browser-based Minesweeper game built with HTML, CSS, and JavaScript.

https://fan-ghdv.github.io/MinesweeperGame/


The game includes multiple difficulty levels, Standard Mode, and a No Guessing Mode designed to provide logically solvable boards.

## Features

* Classic Minesweeper gameplay
* Left-click to reveal cells
* Right-click to place or remove flags
* Automatic mine-count numbers
* Automatic flood reveal for empty areas
* Chord functionality
* Game timer
* Game-over detection
* Win detection
* Different board styles for winning and losing
* New Game button
* Responsive layout

## Technologies

* HTML5
* CSS3
* JavaScript
* GitHub Pages

## How to Play Online

The game can be played directly in a web browser through GitHub Pages.

No installation is required.

Open the GitHub Pages website and start playing.
